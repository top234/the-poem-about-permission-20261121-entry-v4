# The Passcode — entry v4

An entry for the [make.fun competition "the poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235): one original short poem about agency — the power to ask, and to be given.

The program (`main.ts`) writes the poem to `/output/entry.txt`. The poem is 248 Unicode code points, within the 280 limit.

## The poem

> **The Passcode**
>
> In the hospital he cannot speak,
> so I hold up his phone.
> "What's the code?" I ask.
> He only blinks.
>
> I try his birthday. No.
> I try mine. The screen opens.
>
> He'd set the code
> to my birthday
> years ago.
> He was only waiting
> for me to ask.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt`.
